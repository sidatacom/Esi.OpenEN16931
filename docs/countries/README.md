Rollout plan
- Add one folder per European country.
- Keep the same internal files in each folder:
  - `README.md`
  - `ISO_Norms.md`
  - `Validation_Rules.md`
  - `Origins_References.md`
  - `Examples.md`
  - `Tools_Implementations.md`
- Classify content by type, for example:
  - ISO / CEN norms
  - Validation rules
  - National extensions and CIUS variants
  - Examples and test cases
  - Upstream origins references
